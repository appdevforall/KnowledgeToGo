# Introducing Knowledge to Go

Built on the foundation of [Internet-in-a-Box](https://internet-in-a-box.org), Knowledge to Go (K2Go) transforms the most common computing devices in the world into standalone, offline digital learning hubs that deliver a world of information without internet access. 

K2Go turns a phone someone already owns into a knowledge hub for everyone around them, with no technical expertise or additional hardware required. Install K2Go, and download the content you want while you have connectivity. Then, any nearby device with a web browser can connect and browse the content, no internet required. If no local Wi-Fi network is available, K2Go automatically turns the host phone into its own hotspot. 

With a few taps, anyone can clone the K2Go library to their own phones, making it easy to bring resources back to their communities without any hardware that they don't already have. An unlimited number of K2Go servers can be created this way, and only the first one in the chain needed internet access.
