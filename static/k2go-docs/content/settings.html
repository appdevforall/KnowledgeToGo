Settings

 Scroll Prev Top Next More

To access configuration settings and options, tap the Settings tab at the bottom. The Settings page is displayed. Tap any of the following items to make changes:

•Language. See FAQ.

•Theme. Choose from Light, Follow system, or Dark. L

oLight uses a light background with dark text.

oFollow system matches your current device settings.

oDark uses a dark background with light text.

•Help. Displays the K2Go hep files.

•Send feedback. To contact K2Go's developers, type a message in the Describe your feedback field. You can also provide your email address in the Your email (optional) field. When you’re finished, tap Send.

•About. Shows the following:

oApp version. Shows the current version of K2Go.

oCheck for updates. Tap this to see if updates are available (requires internet connection).

oPermissions. Tap this to revisit permissions settings.

oShare usage statistics. Tap the toggle to share or unshare.

oOpen-source licenses. Currently shows “Soon”; not yet available.

oPrivacy. Currently shows “Soon”; not yet available.

•Module management. Add apps to your library:

oDashboard (REST API). The box's REST API core (dash-node), a small Node service that powers every in-app library action (browsing/downloading Books, adding/deleting Wikipedia and ZIM content, Kolibri sessions, Maps, and system status). Unlike the other modules, it can't be installed or removed; it ships with the app and is always present. Tap Rebuild to reinstall it in place when a newer build is available.

oCourse manager. An offline learning platform that includes videos. You can browse and study curated courses, lessons, and exercises. Sample courses are included by default; to add more, tap + Get more. Tap Schedule install to install it in the background, or Install now to install it right away.

oBooks reader. Organize, search, and read books in your offline library. Installing this gets you the reader only; to add books, tap + Get More. Tap Schedule install to install it in the background, or Install now to install it right away.

oContent reader. Reads offline ZIM archives such as Wikipedia and other reference collections. Installing this gets you the reader only; to add Wikipedia and ZIM content, tap + Get More.

oCode on the Go. An offline-ready Android programming environment that lets you create Android apps directly on your device, without needing a computer or internet access. CoGo runs outside K2Go.

oAnalytics. Private, self-hosted usage analytics for your library that helps you understand how content is being used. Nothing to add; analytics apply only to this device.

▪To schedule a time to install analytics,  tap Schedule install.

▪To install analytics immediately, tap Install now.

oNavigate maps. Offline world maps to browse and search on the device. Installing this gets you the base map; if you have internet access, you can add more layers and regions afterward.

•Pending downloads. Shows a live count of queued downloads or “None” if none are queued.

•Backups & recovery. Save your system to a file, restore it, or reinstall from scratch. Tapping this displays the three following options:

oBack up. Saves the current system to a file.

oRestore. Replaces the system from a file.

oReinstall the system. Erases everything and installs a fresh system from scratch.

IMPORTANT: The server stops while any of these actions run.

•Authentication lets you manage sign-ins for the Books and Courses apps, the only two that support login.

•Advanced is for power users, and includes:

oADB. Short for Android Debug Bridge, which is a tool developers use to connect a phone to a computer for advanced debugging and development work. Currently shows “Soon”; not yet available.

oNetwork & DNS. Turn on a custom DNS for the server. Off by default, using 1.1.1.1 (Cloudflare) and 8.8.8.8 (Google).

oTerminal (Debian). Opens a terminal into the underlying Debian environment that K2Go runs on.

Note: This duplicates an older way to reach the same terminal. Press and hold the footer (the app version area) for 3 seconds on any tab. Both methods currently work.

IMPORTANT: The terminal opens outside the Debian environment by default. To reach Debian itself for package management, run iiab --login inside the terminal. Run iiab --help to see further orchestrator commands.
